# MITRE ATT&CK Navigator Lab

This repository contains MITRE ATT&CK Navigator layers and analysis conducted as part of cybersecurity threat intelligence and ATT&CK mapping practice.

## Project Overview

The objective of this lab is to:
- Analyze adversary behaviors
- Map techniques to the MITRE ATT&CK framework
- Compare overlapping techniques used by threat groups
- Improve understanding of threat intelligence and SOC analysis workflows

## Threat Groups Analyzed

### APT39
APT39 is an Iranian threat group known for cyber espionage activities targeting telecommunications, travel, and government sectors.

### OceanLotus
OceanLotus (APT32) is a Vietnam-linked threat group associated with espionage campaigns targeting organizations, governments, and businesses.
